# E-commerce Data Analysis using BigQuery (SQL)

## 📌 Project Overview
This project involves end-to-end analysis of Brazilian e-commerce data using **Google BigQuery Sandbox**. The objective is to answer real-world business questions related to customer behavior, order trends, delivery performance, and logistics efficiency using **SQL-only analytics**.

---

## 🗄️ Data Source
The dataset consists of multiple relational CSV files representing an e-commerce platform:

- `customers.csv` – Customer information and state
- `orders.csv` – Order lifecycle timestamps
- `order_items.csv` – Product-level order details
- `payments.csv` – Payment methods and values
- `products.csv` – Product metadata
- `sellers.csv` – Seller information
- `order_reviews.csv` – Customer ratings and reviews
- `geolocation.csv` – Location mapping data

All datasets were queried using **BigQuery public sandbox environment**.

---

## 🎯 Objectives
- Identify customer purchasing patterns
- Analyze order distribution by time of day
- Measure delivery performance vs estimated delivery dates
- Find states with fastest and slowest deliveries
- Analyze average freight values by region
- Generate actionable business insights using SQL

---

## 🛠️ Tools & Technologies
- **Google BigQuery Sandbox**
- **SQL (Standard SQL)**
  - JOINs
  - Aggregations
  - CASE statements
  - Date & time functions
  - Subqueries
  - ORDER BY & LIMIT

---

## 📊 Key Analyses Performed
- Time-of-day order analysis (Dawn, Morning, Afternoon, Night)
- State-wise delivery speed comparison using date differences
- Freight value analysis across states
- Customer distribution by region
- Order and logistics performance evaluation

---

## 📈 Insights & Findings
- Certain states consistently receive orders earlier than the estimated delivery date
- Afternoon and night time slots show higher order volume
- Freight costs vary significantly by region
- Delivery efficiency plays a key role in customer experience
